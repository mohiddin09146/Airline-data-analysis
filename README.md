#✈️ Airline-data-analysis
In this project, I am prominently trying to Analyse the airline data set, First I made a Dashboard in order to have an overview of the data, then I perform Data analysis in Jupyter Notebook according to the problem statement, and then make a final report

🧭 Project Overview
This project follows a structured analytical pipeline:

1.Dashboard Overview: Built an interactive Microsoft Power BI dashboard to establish high-level operational KPIs and data visibility.

2.Deep-Dive Analysis: Performed granular data cleaning, exploratory data analysis (EDA), and outlier treatment using Python inside a Jupyter Notebook.

3.Strategic Reporting: Synthesized findings into a comprehensive final report addressing core problem statements and research questions

🛠️ Tech Stack & Libraries

. Languages: Python, DAX

. Business Intelligence: Microsoft Power BI

. Data Processing & Analysis: Pandas, NumPy

. Data Visualization: Matplotlib, Seaborn

. Tools: Jupyter Notebook, Git

🔄 Workflow & Methodology

📊 1. Dashboard Development
- Data Cleaning & Modification: Handled missing values, standardized formats, and structured relational fields.

- KPI Definition: Established core business metrics to track flight performance and operational efficiency.

- DAX Calculations: Computed custom measures for advanced aggregations and metric filtering.

- Visual Design: Selected intuitive chart types optimized for executive reporting.

🐍 2. Python-Based Data Analysis

- Ingestion & Loading: Imported raw datasets into Pandas dataframes.

- Sanitization: Addressed structural inconsistencies, duplicates, and missing values.

- Outlier Removal: Applied statistical methods (such as IQR filtering) to remove extreme anomalies that could skew insights.

- Exploratory Analysis: Uncovered hidden trends, correlations, and performance bottlenecks.
